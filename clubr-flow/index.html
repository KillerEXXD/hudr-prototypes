ClubR — How It Works

A web PWA that is the transparent scorekeeper for a poker club's games: FT Fantasy — a fantasy contest on a streamed Final Table (launch format: Stack Draft) — and Last Longer — the club's own live tournament. ClubR tracks and proves the count and the result. It awards nothing, holds nothing, and never touches the cash. Clubs settle all stakes offline.

Be the tool, not the bank. Pay a flat fee to use it (credits, or a subscription) — the money stays between the players.

⚡ Launches standalone — Phase 1 (no HUDR). The ClubR operator hand‑enters each FT's chip stacks → the app computes ICM prices, then enters the public finishing order to score. Phase 2 automates this off a HUDR live feed. Ships in ~2–3 days.

1.

Why ClubR exists

Today a club's Last Longer runs on paper / WhatsApp. Players pay the host cash; the host tracks who's in and out. The players never see the true headcount — so a dishonest host can hide players and pocket the money. ClubR makes the count un‑hideable.

The problem today

🩹 Blind trust in the host

Was it 30, 35, or 40 entries? Nobody knows but the host. Eliminated players stop paying attention, so the host can under‑report the count and pocket the early‑busted players' buy‑ins. Chips, eliminations and the chop are all on the host's word.

🤷 Hidden headcount 📝 Paper / WhatsApp 🙈 No proof, no audit
What ClubR does

🔎 The notary, not the bank

Every player self‑joins in the app and is publicly visible — so the count can't be faked. Results are tamper‑proof — the public FT finishing order for FT Fantasy (operator‑entered in Phase 1, HUDR‑automated in Phase 2); logged + player‑confirmable for Last Longer. The cash stays between the host and players; the app never knows, holds, or promises it.

👀 Public, un‑hideable count 🧾 Visible audit log 🚫 App never touches money
2.

Two features — one job

Both features are the same kind of thing: a transparent scorekeeper. The app awards nothing and settles nothing — it proves the count and the result, you pay a flat fee to use it, and the club handles the stakes offline. They differ only in where the truth comes from.

Feature A · Fantasy

🎯 FT Fantasy · Stack Draft

Members get a budget and draft 4 of the 9 finalists, each priced by ICM, and enter a bucket (a Stakes tier). The result comes from the public finishing order — operator‑entered in Phase 1, HUDR‑automated in Phase 2 — verifiable, not a private judgment. The app shows the ranking; the club settles offline.

Truth = public FT result ICM‑priced · verifiable App awards nothing
Feature B · Track

🏟️ Last Longer

The club runs its own live tournament. Players self‑join (so the count is public & un‑hideable); they self‑report chips; the host judges eliminations — and every host action is logged for all to see. Last one standing (or a chop) wins — offline.

Truth = host, fully logged Public self‑join count App awards nothing

Roles & Permissions

In Phase 1 the operator enters the FT data; owners hold the paid subscription and run the club; hosts run games (earn nothing — reputation only); players self‑join and pay per game with credits. HUDR automates the data & waives player fees in Phase 2.

Operator · Phase 1

Enters the FT data

ClubR enters each FT's chip stacks → ICM prices, and the public finishing order to score. HUDR replaces this in Phase 2.

Owner

Holds the subscription

Buys the ClubR subscription (premium). Creates the club, assigns admins/hosts. Required to host. (Phase 2: includes HUDR.)

Host / Admin

Runs games

FT Fantasy: opens contests on the priced FTs. Last Longer: runs the live game, judges eliminations. Earns nothing; every action is logged.

Player

Self‑joins & plays

Joins via phone + OTP. Pays a flat fee per entry (credits). Drafts in FT Fantasy; plays in Last Longer. (Phase 2: a HUDR sub plays free.)

HUDR · Phase 2

Automates the data

Later, HUDR auto‑feeds the chip stacks + finishing order (removes the manual step), and a HUDR sub waives the player fee. Last Longer never uses HUDR.

Hosting and playing are paid separately. The owner subscribes to host; players pay per game with credits. A subscription never makes the app hold or move money — it just unlocks the tool. Phase 1 = credits + host subscription (free / invite‑only pilot); the HUDR perks below switch on in Phase 2.

The Wall — “the tool, not the bank”

The whole posture in five rules. Everything of value — the cash — is offline and invisible to the app.

✓The app awards, holds, pools, and promises nothing. No prize, no payout, no coin pool, no points — for either feature. It records and proves a count and a result.
✓All cash is offline and app‑blind. No IOUs, no cash ledger. The app shows counts, statuses and results in “Stakes,” never dollars.
✓Players self‑join and are publicly visible — so the host can't fake the headcount. That transparency is the product.
✓No peer‑to‑peer credit transfer. Credits are a fee paid to use the tool — never sent between users.
✓Credits are a facilitation fee, never a prize. You pay to be provably counted; you don't “win” anything inside the app.
