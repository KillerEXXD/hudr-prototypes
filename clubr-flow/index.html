ClubR — How It Works

A PWA where a poker club offers its members two independent, coin‑based games: FT Fantasy — bet coins on an external Final Table — and Last Longer — join a coin pool in the club's own live tournament. Both pay out in 🪙 coins.

Set the club up once, then run either feature (or both). They share the club & members — nothing else.

Owner Admin Member Guest HUDR (FT Fantasy only)
1.

Two distinct features

The single most important thing: FT Fantasy and Last Longer are separate. One is betting on an outside game; the other is the club running its own game. They never depend on each other.

Feature A · Betting

🎯 FT Fantasy

Members are fans/bettors on an external Final Table. They pick FT players, choose a bucket (pool), and stake coins. The real FT result decides which pool wins; coins are distributed.

External Final Table (via HUDR) Users = bettors, not players 🪙 coin pools
Feature B · Play

🏟️ Last Longer

The club hosts its own live poker tournament. Members are the players; they join a coin pool; the admin manages the live game and tracks who lasts longest. Last one standing wins the pool.

Club's own live tournament Members = players Admin‑managed · no HUDR 🪙 coin pool

3.

Roles & Permissions

Owners & admins run the club & games; members play/bet with coins; guests can be invited into a game.

Owner

Runs the club

Creates the club, manages members & roles, invite code; can do anything an admin can.

Admin

Runs the games

FT Fantasy: opens buckets, resolves pools. Last Longer: hosts the live tournament, tracks chips/eliminations, settles the pool.

Member

Plays & bets

FT Fantasy: picks + stakes coins. Last Longer: joins the coin pool as a player. Sees own profile & leaderboards.

Guest

Invited in

Can be invited into a game via a link, buy in with coins, and appear on its leaderboard.

⚙️ HUDR — feeds FT Fantasy only

Provides the external Final Table + live results that resolve FT Fantasy pools. Last Longer does not use HUDR — the admin manages that live event directly.

9.

HUDR Integration

FT Fantasy only

HUDR powers only FT Fantasy — it supplies the external Final Table being bet on. Last Longer does not use HUDR (the admin runs that live event directly).

📡 HUDR provides

  • The external Final Table (9 players)
  • Live chip counts & eliminations
  • Final finishing order / results
⟶

🎯 FT Fantasy uses it to

  • Show the FT players to pick from
  • Resolve which bucket / pool won
  • Distribute the coin pool

🏟️ Last Longer — no HUDR

It's the club's own live tournament; the admin enters chips & eliminations manually. Self‑contained.
