2.

Roles & Permissions

Who can do what inside a club. Owners & admins run the club; members play; guests join Last Longer games via a share link.

Owner

Runs the club

Creates the club, manages members & roles, sees the invite code, can do everything an admin can.

Admin

Runs the events

Creates tournaments, links HUDR, creates Buckets & Last Longer games, tracks payments, finalizes results.

Member

Plays

Joins games, picks players, pays entry, chats, follows live standings, sees their cross‑tournament profile.

Guest

Joins via link

Non‑members can join a Last Longer game through a shareable link, pay, and appear on its leaderboard.

⚙️ HUDR / System

Not a person — the integration that feeds the final table, participants, and live eliminations/scoring that drive every game.

9.

HUDR Integration

System

ClubR doesn't track the poker itself — it consumes live tournament data from HUDR to score every game.

📡 HUDR provides

  • The 9‑player final table (A–I)
  • Tournament participants / users
  • Live eliminations & finishing order
  • Real‑time results feed
⟶

🃏 ClubR consumes for

  • FT Fantasy placement scoring (Buckets)
  • Last Longer chip / elimination updates
  • Live leaderboards & finalize/payouts
  • Member stats & season standings
