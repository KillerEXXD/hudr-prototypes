# Survey — SUS + SEQ + preference + value

Paste into Google Forms / Typeform. Run **one SUS block per variant** the
participant used (so you get a comparable score per prototype).

---

## Screener (start)
1. How would you describe your poker experience? *(Recreational / Serious amateur / Pro or coach / Content creator)*
2. How comfortable are you with poker stats like VPIP, 3‑bet, c‑bet? *(1 Not at all … 5 Very)*
3. Which prototype are you rating? *(Scout Engine / Crisp / Stats / Sharp)*

---

## SEQ — after each task (Single Ease Question)
> **Overall, how difficult or easy was it to complete that task?**
> `1 Very difficult — 2 — 3 — 4 — 5 — 6 — 7 Very easy`

(Repeat per task. The single most predictive, lowest‑effort usability metric.)

---

## SUS — System Usability Scale (the industry standard)
Rate each: **1 Strongly disagree … 5 Strongly agree.**

1. I think that I would like to use this app frequently.
2. I found the app unnecessarily complex.
3. I thought the app was easy to use.
4. I think I would need help from a knowledgeable person to use this app.
5. I found the various functions in this app were well integrated.
6. I thought there was too much inconsistency in this app.
7. I would imagine most people would learn to use this app very quickly.
8. I found the app very cumbersome to use.
9. I felt very confident using the app.
10. I needed to learn a lot before I could get going with this app.

**Scoring (0–100):** odd items → (response − 1); even items → (5 − response);
sum all ten, × 2.5. **Benchmark: 68 = average; 80+ = excellent; <50 = serious problems.**

---

## Trust & UI
11. "The reads in this app felt trustworthy." *(1–5)*
12. "The app looked polished / professional." *(1–5)*
13. *(Sharp only)* "I understood which numbers were measured vs **estimated**." *(1–5)*

---

## Value & features
14. What was the **most valuable** thing in the app? *(short text)*
15. What was the **least valuable** / would you cut? *(short text)*
16. What's **missing** that you'd need before using it for real? *(short text)*
17. Would you use this for your own game? *(Definitely not … Definitely — 1–5)*
18. Would you pay for it? *(No / Maybe / Yes)* — if yes, **how much per month?** *(text)*
19. **NPS:** How likely are you to recommend this to a poker friend? *(0–10)*

---

## Comparative (only if they saw multiple variants)
20. Which version would you actually use? *(Engine / Crisp / Stats / Sharp)* — why? *(text)*
21. Which felt **easiest**? Which looked **most trustworthy**? *(text)*
